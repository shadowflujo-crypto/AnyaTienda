Respaldo & Sincronización GitHub

GitHub sirve como respaldo del estado de tu tienda. No es necesario para que Firebase funcione.

¿Qué datos son estos?
Token: permiso para guardar el respaldo. Usuario: tu nombre de GitHub. Repositorio: nombre exacto del repositorio. Archivo: dónde guardar el JSON. Rama: normalmente main. El token no es tu contraseña de GitHub.
1 · Crea un repositorioEn GitHub crea un repositorio, por ejemplo anya-streaming-backup. No necesitas subir manualmente el JSON.
2 · UsuarioEs tu nombre de usuario de GitHub, el que aparece en tu perfil.
3 · RepositorioSolo el nombre del repositorio, sin https://github.com/.
4 · TokenCrea un Fine-grained Personal Access Token con acceso únicamente al repositorio de respaldo y permiso Contents: Read and write.
5 · ArchivoPuedes dejar anya_stream_database.json. El sistema lo crea o actualiza.
6 · RamaSi tu repositorio usa la rama principal habitual, escribe main.
